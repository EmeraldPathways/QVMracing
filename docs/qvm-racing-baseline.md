# QVM Racing Workbench baseline

This project is a separate racing-only build. The protected QVM Football Workbench, its database, credentials, worker state, and paper history are not copied or modified.

- Product: QVM Racing Workbench
- Local database name: `qvm_racing.sqlite3`
- Site variable: `QVM_RACING_SITE_URL`
- Worker secret: `QVM_RACING_WORKER_SHARED_SECRET`
- Provider default: `demo`
- Trading mode: paper positions only
- Deployment: held for explicit approval
